Compatibility checks

OK

CPU ↔ board

AM5 socket. X870 boards ship with BIOS support for Ryzen 9000, and AM5 is confirmed for Zen 6.

OK

GPU length

303 mm card in a case that takes 392 mm.

OK

Power budget

≈120 W CPU + 360 W GPU + ≈80 W rest ≈ 560 W peak on an 850 W unit.

OK

GPU power cable

RM850x has a native 12V‑2×6 lead. Push it in fully until it clicks; no adapters.

OK

Cooler fit

Lancool 216 takes a 360 mm radiator on top, so the front stays clear for the 160 mm intake fans and the GPU.

OK

Memory

2 sticks in A2/B2. Turn on EXPO in BIOS to run at 6000. Two sticks run faster on AM5 than four.
